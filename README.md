# GitHub Enterprise field guide

A yes/no self-assessment, for phone or desktop, for designing GitHub Enterprise as a governed service: platform choice, identity and provisioning, roles, external users, on- and offboarding, audit, licensing, cost and ITSM fulfilment.

**Read it:** https://ragmha.github.io/github-enterprise-field-guide/

- Each answer gives a recommendation with a link to the official docs, which stay the source of truth. This is an aid for ordering decisions, not a replacement for them.
- Answers are saved in your browser only.
- Every product and price claim links to an official source in the [evidence ledger](https://ragmha.github.io/github-enterprise-field-guide/ledger.html).
- Generic guidance, not tied to any organization. Products and prices change, so confirm account-specific terms with your account team.

Plain HTML, CSS and SVG with no build step. Found something out of date? Open an issue.
